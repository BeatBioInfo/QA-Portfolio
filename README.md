## What is this Repository about?

- This repo contains automation code for the following using Selenium Framework for web testing, Appium & Maestro for mobile app testing, and Postman for APIs (functionality):
- Demo Website: [https://katalon-demo-cura.herokuapp.com/],[https://formy-project.herokuapp.com/],[https://www.demoblaze.com/], [https://www.automationexercise.com/]
- Test Suite used the Page Object Model and tested different functionalities on the app or website including but not limited to the following - Login Page, Home Page, Book an Appointment Page with assertions
- The build tool for the project is Maven.
- TestNG is the testing framework for organizing and running tests and performing Assertions
- Tests are run on Chrome, Edge, and Firefox browsers using their respective WebDriver.
